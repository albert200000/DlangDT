# DlangDT

Eclipse IDE plugin for D language development.

## Features

- editor support using TextMate grammar
- IDE features using LSP server `serve-d`
- dub project building
- dub project launching

## Installation

1. Install the DlangDT Eclipse plugin from the marketplace.
2. Ensure `dub` and `serve-d` are available on PATH, or set paths in preferences (`Window → Preferences → DlangDT`).
3. `serve-d` requires `dcd-client` and `dcd-server` binaries; these must be available on PATH.
